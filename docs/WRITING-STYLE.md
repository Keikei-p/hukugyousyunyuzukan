# 副業収入図鑑 執筆スタイル

このサイトは、機械的な説明文ではなく「人が読んで分かりやすい図鑑」を目指します。

## 基本方針

- 事実・条件・注意点を優先し、架空の体験談や実績は作らない。
- 「AIを使ったこと」を隠すためではなく、読者にとって自然で具体的な文章へ編集する。
- 同じ構文や語尾を記事間で使い回さない。
- 「〜しましょう」を連続させず、「〜してみる」「〜を確認する」「〜でも十分」など自然に変える。
- 抽象的な助言だけで終わらせず、30秒の動画、3件の商品、15分の講座など具体的な練習例を入れる。
- 一文の長さをそろえすぎない。短い文も混ぜる。
- 必要以上に断定しない一方、「場合があります」を連発しない。
- 読者に不安をあおる表現、収益保証、根拠のないランキングを使わない。

## 記事ごとに変える部分

1. 最初の一歩は、その仕事で本当に試せる小さな行動にする。
2. 手順は仕事内容固有の順番にする。汎用テンプレートをコピーしない。
3. 注意点は、その仕事で起こりやすい具体的な問題を書く。
4. 費用は「安い・高い」だけでなく、何に費用が発生するかを書く。
5. FAQは検索されそうな疑問だけでなく、読者が実際に迷いそうな点を選ぶ。
6. 練習課題は完成物が想像できる内容にする。

## 避ける表現

- 誰でも簡単に稼げる
- 必ず収益化できる
- これだけでOK
- おすすめNo.1（根拠がない場合）
- AIが全部やってくれる
- 実際にやってみた、稼げた、利用した、など未確認の体験談

## 最終チェック

公開前に、同じページで同じ語尾が3回以上続いていないか、他の記事と手順文がほぼ同じになっていないかを確認します。
